## Зависимости этапов

Для M1 длительный анализ должен выполняться вне HTTP event loop. До RabbitMQ
возможен ограниченный вызов в отдельном процессе с ожиданием результата;
конкретное решение требуется перед реализацией анализа. Не следует маскировать
недолговечные `BackgroundTasks` под надёжную очередь заданий.

NumPy, SciPy, rosu-pp-py, HTTPX в runtime, RabbitMQ и Redis добавляются только
под конкретные сценарии. На M0 HTTPX нужен исключительно для тестов API.
osu! API v2 и разрешённый сетевой импорт исследуются отдельно, когда появится
соответствующая задача. Первым источником будут локальные `.osu`.
