# Исследования

Экспериментов пока не проводилось. Здесь будут проверяться гипотезы анализа,
а не записываться произвольные эвристики как установленные игровые навыки.

Для каждого `YYYY-MM-DD-topic.md` указывайте:

- Гипотезу и операциональное определение проверяемого признака.
- Данные, их происхождение, разрешения и разделение train/validation/test.
- Версию алгоритма, параметры, checksum и команду воспроизведения.
- Метод оценки и baseline.
- Измеренные результаты, включая отрицательные и неопределённые.
- Ошибочные примеры, ограничения и выводы.

Первый возможный эксперимент: описывает ли вариативность inter-hit intervals
finger control лучше простого BPM baseline? До разметки карт и выбора метрики
положительный ответ не заявляется. Синтетический тест подтверждает математику,
но сам по себе не подтверждает валидность игрового навыка.
